# Лабораторные работы по численным методам

## Содержание

### I. Решение нелинейных уравнений и систем

#### 1. **Лабораторная работа 1**

   - Оценка погрешности
   - Критерии остановки итерационного процесса

#### 2. **Лабораторная работа 2**

   - Проверка условия сходимости
   - Практическое применение метода

#### 3. **Лабораторная работа 3**
   **Приближенное решение уравнения f(x) = 0 методом Ньютона**

   - Выбор начального приближения
   - Сравнение скорости сходимости с другими методами

#### 4. **Лабораторная работа 4**

   - Теорема Штурма
   - Численные методы для полиномов
